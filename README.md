# Horizontal Pragmatic Drag and Drop Task Board

A standalone React + TypeScript + Vite example based on the uploaded Atlassian Pragmatic Drag and Drop board example.

## Layout

- Employees are horizontal rows.
- Tasks are laid out horizontally inside each employee row.
- Drag tasks left/right to reorder them.
- Drag tasks into another employee row to move them.
- Rows can also be reordered horizontally.
- The task rows remain fixed-height.
- The board has horizontal scrolling.

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.
